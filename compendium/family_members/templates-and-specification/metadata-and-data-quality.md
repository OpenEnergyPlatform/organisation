### Example metadata use cases

There are several use cases where information from metadata objects like the OEMetadata are helpful to understand the context of the subject (energy scenario data & general public data in our case).

- Retrieve user activity based on metadata information like publishing and contribution information.

- Link related resources and create linked open data while describing your data in "atomic" detail. Enable users to understand your data and make it more accessible.

- Provide context information about each dataset (tabular data resources).

- Store information relevant to internal functionality. This also requires extensive validation for the OEMetadata specification. By using the json schema specification and additionally support tooling like the datapackage format the spec. is accessible for every programming language. But most of the tools are developed for python not only due to its popularity in the energy system research context.
